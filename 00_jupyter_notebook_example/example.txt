ЧТО МЫ СОЗДАЛИ
==============

Виртуальное окружение Python (папка .venv в проекте).

Это отдельная копия Python только для этого проекта, со своим набором
библиотек. Библиотеки, установленные сюда, не смешиваются с системным
Python и с другими проектами. Если окружение сломается, папку .venv можно
просто удалить и создать заново.

В окружение установлены:
  opencv-python  - библиотека cv2 (компьютерное зрение: картинки, видео, камера)
  numpy          - работа с массивами (картинка в cv2 это массив numpy)
  matplotlib     - графики и показ картинок прямо в блокноте
  ipykernel      - "мост", через который VS Code запускает блокноты на этом Python

Код выполняется локально, на этом компьютере (не в Colab).
Поэтому работают cv2.imshow (отдельное окно) и веб-камера,
и файлы из папки проекта (например video.mp4) доступны напрямую.


ЧТО ТАКОЕ .ipynb
================

.ipynb - это Jupyter Notebook (блокнот). Файл состоит из ячеек:

  Code      - ячейка с кодом Python. Запуск: Shift+Enter.
              Результат (print, картинки, ошибки) появляется прямо под ячейкой.
  Markdown  - ячейка с текстом/заметками/заголовками. Не выполняется,
              Shift+Enter просто превращает её в оформленный текст.
              Двойной клик - снова редактировать.

Ядро (kernel) - это запущенный Python, который выполняет ячейки.
Он "помнит" всё, что уже выполнено: переменные из одной ячейки
доступны в следующих. Поэтому ячейки обычно запускают сверху вниз.

Полезные кнопки сверху блокнота:
  + Code / + Markdown  - добавить ячейку
  Run All              - выполнить все ячейки по порядку
  Restart              - перезапустить ядро (вся память стирается)
  Clear All Outputs    - убрать все результаты под ячейками
  Variables            - посмотреть текущие переменные


ПОРЯДОК НАСТРОЙКИ В VS CODE
===========================

1. Проверить, что Python установлен (в терминале):
     python -V
   (у нас Python 3.14.4)

2. Установить расширения в VS Code (Ctrl+Shift+X):
     Python   (Microsoft)
     Jupyter  (Microsoft)

3. Открыть терминал в папке проекта и создать окружение:
     python -m venv .venv
   -> в проекте появится папка .venv

4. Активировать окружение:
     .venv\Scripts\activate
   -> в начале строки терминала появится (.venv)
   (если PowerShell запрещает запуск скриптов, один раз выполнить:
     Set-ExecutionPolicy -Scope CurrentUser RemoteSigned )
  выйти в терминале deactivate

5. Установить библиотеки (при активном (.venv)):
     pip install opencv-python numpy matplotlib ipykernel
   -> в конце "Successfully installed ..."

6. Открыть блокнот .ipynb -> справа вверху Select Kernel
   -> Python Environments -> выбрать .venv (Python 3.14.4)
   Делается один раз для каждого блокнота.

7. Запускать ячейки: Shift+Enter (по одной) или Run All (все).


ДОБАВИТЬ НОВУЮ БИБЛИОТЕКУ ПОТОМ
===============================
В терминале с активным (.venv):
     pip install имя_библиотеки
Затем в блокноте можно нажать Restart, чтобы ядро её увидело.
